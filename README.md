# CodeRamp: practice floor for new medical coders (proof of concept)

Trainee coders code **synthetic** patient charts (no real patient data), get instant scoring and explanations,
track progress toward 95% accuracy, and prepare for CCA/CPC-style exams.

- Single static page (`index.html`), no backend; progress is saved in the visitor's browser.
- Answer keys are a draft pending review by a certified coder (CPC/CCS). Use the current ICD-10-CM, CPT and HCPCS code books as the authority.
- CPT descriptions are paraphrased.
